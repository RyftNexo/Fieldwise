# Claude Code final-stage rules

AGENTS.md is binding and takes precedence over older exclusive-owner wording in area conventions or skills. All roles may edit all project paths after syncing the final-stage ownership map. Area-specific technical conventions still apply.

Check active tasks and open PRs for overlaps before writing; coordinate handoffs instead of overwriting work. Keep your own role, task IDs and role-prefixed branch. Use task-start, task-finish and sync. Make focused changes, preserve contracts and fixture mode, run verification and affected feature flows, and complete the PR handoff.

Hooks remain enabled. If a guard blocks an action, stop and inspect the cause; do not work around it. Shared ownership removes path exclusivity only, not secret, branch or main protections. Never disable checks or weaken authentication/validation to pass a test.
